# Database schema

PostgreSQL 17 + pgvector 0.8.7, Prisma 7.10.1. Schema: `apps/api/prisma/schema.prisma`.
Migrations: `apps/api/prisma/migrations/`. Roles and RLS model: [ADR-003](architecture/ADR-003-database-roles-and-rls.md).

## Conventions

| Rule             | Implementation                                                                                                           |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Naming           | snake_case tables/columns (`@@map`/`@map`), camelCase in TypeScript                                                      |
| Primary keys     | UUIDv7 generated by Prisma (`@default(uuid(7))`), type `uuid`                                                            |
| Timestamps       | `timestamptz(6)`; `created_at` default `now()`, `updated_at` maintained by Prisma **and** trigger `app.set_updated_at()` |
| Soft delete      | `deleted_at timestamptz NULL` where business records must be retained                                                    |
| Money            | `numeric(20,4)` (or tighter per column); never float. App math via `@hrm/business-rules`                                 |
| Tenancy          | `organization_id uuid NOT NULL` + RLS policy on every tenant-owned table                                                 |
| Constraints      | CHECK constraints, RLS, triggers and functions are hand-written in migration SQL                                         |
| Append-only      | `app.prevent_mutation()` trigger + privilege revocation (audit, finalized payroll snapshots)                             |
| Effective dating | `effective_from date NOT NULL`, `effective_to date NULL`, exclusion/overlap checks (from Phase 03)                       |

## Helper schema `app`

| Object                                 | Purpose                                                 |
| -------------------------------------- | ------------------------------------------------------- |
| `app.current_organization_id() → uuid` | Tenant of the current transaction (NULL if unset)       |
| `app.set_updated_at()` trigger fn      | Keeps `updated_at` correct for raw SQL writes           |
| `app.prevent_mutation()` trigger fn    | Raises on UPDATE/DELETE/TRUNCATE for append-only tables |

## Tables (Phase 01)

### `organizations` — tenant root

| Column                  | Type                       | Notes                                                  |
| ----------------------- | -------------------------- | ------------------------------------------------------ |
| id                      | uuid PK                    | UUIDv7                                                 |
| slug                    | citext UNIQUE              | `^[a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?$` (CHECK)       |
| name                    | varchar(200)               | not blank (CHECK)                                      |
| legal_name              | varchar(300) NULL          |                                                        |
| status                  | enum `organization_status` | ACTIVE / SUSPENDED / ARCHIVED, default ACTIVE; indexed |
| default_timezone        | varchar(64)                | IANA, default `Asia/Kolkata`                           |
| default_currency        | char(3)                    | ISO 4217 (CHECK `^[A-Z]{3}$`), default `INR`           |
| default_locale          | varchar(35)                | BCP 47, default `en-IN`                                |
| created_at / updated_at | timestamptz                | trigger-maintained `updated_at`                        |
| deleted_at              | timestamptz NULL           | CHECK `deleted_at >= created_at`                       |

RLS: `organizations_tenant_isolation` (ALL) — `id = app.current_organization_id()`.
Runtime role privileges: SELECT, UPDATE only (no INSERT/DELETE).

### `audit_logs` — append-only audit trail

| Column                  | Type                            | Notes                                            |
| ----------------------- | ------------------------------- | ------------------------------------------------ |
| id                      | uuid PK                         |                                                  |
| organization_id         | uuid FK → organizations(id)     | ON DELETE/UPDATE RESTRICT                        |
| actor_type              | enum `audit_actor_type`         | USER / SYSTEM / API_CLIENT / AI_AGENT            |
| actor_id                | uuid NULL                       | required when actor_type = USER (CHECK)          |
| action                  | varchar(100)                    | dotted verb, e.g. `organization.updated` (CHECK) |
| entity_type / entity_id | varchar(100) / varchar(64) NULL |                                                  |
| request_id              | varchar(64) NULL                | correlates with API logs                         |
| ip_address              | inet NULL                       |                                                  |
| user_agent              | varchar(512) NULL               |                                                  |
| changes / metadata      | jsonb NULL                      | redact sensitive values before writing           |
| occurred_at             | timestamptz                     | default now()                                    |

Indexes: `(organization_id, occurred_at DESC)`, `(organization_id, entity_type, entity_id)`,
`(organization_id, actor_id)`.
RLS: `audit_logs_tenant_select` (SELECT), `audit_logs_tenant_insert` (INSERT WITH CHECK).
Triggers: `audit_logs_append_only` (UPDATE/DELETE), `audit_logs_no_truncate`.
Runtime role privileges: SELECT, INSERT only.

## Tables (Phase 02 — identity, access control, subscriptions)

Identity tables are **global** (a user can belong to several organizations) and have no tenant RLS;
they are reached only through the identity services. Tenant tables have RLS and composite
`(organization_id, id)` foreign keys.

| Table                   | Scope   | Purpose / key constraints                                                                                                                                                                                                                                                                                   |
| ----------------------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `users`                 | global  | `email citext UNIQUE` (format CHECK), argon2id `password_hash`, `status`, `mfa_enabled` (CHECK: requires encrypted secret), `mfa_secret_encrypted` (AES-256-GCM), `mfa_recovery_code_hashes text[]`, `failed_login_count ≥ 0`, `locked_until`, `last_login_at`, `password_changed_at`; `updated_at` trigger |
| `sessions`              | global  | one per device sign-in; `active_organization_id` FK (SET NULL), `expires_at > created_at`, `revoked_at`, `revoke_reason`; index `(user_id, revoked_at)`                                                                                                                                                     |
| `refresh_tokens`        | global  | `token_hash char(64) UNIQUE` (hex CHECK), `expires_at`, `used_at` (rotation / reuse detection); cascade with session                                                                                                                                                                                        |
| `auth_events`           | global  | append-only security log (trigger + revoked UPDATE/DELETE/TRUNCATE); enum `auth_event_type`; indexes `(user_id, occurred_at DESC)`, `(email, occurred_at DESC)`                                                                                                                                             |
| `password_reset_tokens` | global  | `token_hash UNIQUE`, `expires_at`, `used_at` (single use)                                                                                                                                                                                                                                                   |
| `permissions`           | catalog | `key` PK (`a.b.c` CHECK); seeded by migration; read-only for `hrm_app`                                                                                                                                                                                                                                      |
| `memberships`           | tenant  | `UNIQUE(organization_id, user_id)`, `UNIQUE(organization_id, id)`; `status` ACTIVE/SUSPENDED; RLS tenant + own-read-without-tenant                                                                                                                                                                          |
| `roles`                 | tenant  | `UNIQUE(organization_id, key)` (key CHECK), `UNIQUE(organization_id, id)`, `is_system`                                                                                                                                                                                                                      |
| `role_permissions`      | tenant  | PK `(role_id, permission_key)`; FK `(organization_id, role_id) → roles` CASCADE; FK `permission_key → permissions`                                                                                                                                                                                          |
| `membership_roles`      | tenant  | FK `(organization_id, membership_id) → memberships` CASCADE, FK `(organization_id, role_id) → roles` RESTRICT; `scope_type` enum + `scope_id` (CHECK: required only for structural scopes); `UNIQUE … NULLS NOT DISTINCT` per assignment                                                                    |
| `invitations`           | tenant  | `token_hash UNIQUE`, `role_ids uuid[]` (≥ 1), `status`, `expires_at`; partial unique `(organization_id, email) WHERE status = 'PENDING'`                                                                                                                                                                    |
| `subscription_plans`    | catalog | `key UNIQUE`, `limits jsonb`; seeded `trial`; read-only for `hrm_app`; **no prices modelled**                                                                                                                                                                                                               |
| `subscriptions`         | tenant  | `UNIQUE(organization_id)`, `status` enum, `trial_ends_at` (CHECK required when TRIALING), period CHECK; no DELETE for `hrm_app`                                                                                                                                                                             |

Functions: `app.current_user_id()` (from `app.user_id`), `app.invitation_tenant(token_hash)`
(SECURITY DEFINER; returns only the organization id).

## Tables (Phase 03 — organization structure and calendars)

All 13 tables are tenant-owned: `organization_id` NOT NULL, RLS policy `<table>_tenant_isolation`
(`organization_id = app.current_organization_id()`), `UNIQUE(organization_id, id)` for composite
foreign keys, `status` enum `record_status` (ACTIVE / INACTIVE — archive instead of delete),
`updated_at` trigger. Business codes are `UNIQUE(organization_id, code)` and match
`^[A-Z0-9][A-Z0-9_-]{0,19}$` (CHECK); names must not be blank (CHECK).

| Table               | Key columns / constraints                                                                                                                                                                                                    |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `companies`         | `code`, `name`, `country_code` (ISO 3166 CHECK, default IN), `default_currency` (ISO 4217 CHECK), `timezone`                                                                                                                 |
| `legal_entities`    | composite FK → companies; `legal_name`, `country_code`; India identifiers `pan`, `tan`, `gstin`, `cin` with format CHECKs and **GSTIN must embed the PAN** (CHECK); `registration_number`; optional `registered_location_id` |
| `locations`         | address lines, `city`, `state`, `postal_code`, `country_code`, `timezone`; `latitude`/`longitude` `numeric(9,6)` — both or neither, ranges ±90 / ±180 (CHECK)                                                                |
| `branches`          | composite FK → companies; optional `legal_entity_id` (trigger: must belong to the **same company**), `location_id`, `work_week_id`, `holiday_calendar_id`, `timezone`                                                        |
| `cost_centers`      | optional `company_id` (NULL = organization-wide)                                                                                                                                                                             |
| `departments`       | composite FK → companies; optional `parent_id` (self), `cost_center_id`; CHECK not own parent; trigger `app.department_hierarchy_guard`: parent in the same company, **no cycles**, depth ≤ 10                               |
| `teams`             | composite FK → departments                                                                                                                                                                                                   |
| `job_grades`        | `rank` 1–1000 (CHECK), `UNIQUE(organization_id, rank)`, `description`                                                                                                                                                        |
| `designations`      | optional `job_grade_id`, `description`                                                                                                                                                                                       |
| `work_weeks`        | `name`, `description`, `is_default` — partial unique index: **one default per organization**                                                                                                                                 |
| `work_week_rules`   | composite FK → work_weeks (CASCADE); `weekday` 1–7 (ISO), `occurrence` 0–5 (0 = every week, n = nth weekday of the month), `day_type` enum FULL / HALF / OFF; `UNIQUE(work_week_id, weekday, occurrence)`                    |
| `holiday_calendars` | `name`, `description`, `is_default` — partial unique index: one default per organization                                                                                                                                     |
| `holidays`          | composite FK → holiday_calendars (CASCADE); `date` (`date`), `name`, `kind` enum PUBLIC / OPTIONAL; `UNIQUE(calendar_id, date)`                                                                                              |

Integrity functions (all `SECURITY DEFINER`, fixed `search_path`):

| Function / trigger                       | Purpose                                                                                                                                                                                                |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `app.enforce_same_tenant()`              | Optional (nullable) references cannot use composite FKs in Prisma; this trigger rejects a referenced row from another organization (legal entities, branches, cost centers, departments, designations) |
| `app.branch_legal_entity_same_company()` | A branch's legal entity must belong to the branch's company                                                                                                                                            |
| `app.department_hierarchy_guard()`       | Same-company parent, cycle detection, maximum depth 10                                                                                                                                                 |
| `app.membership_role_scope_target()`     | `membership_roles.scope_id` must reference an existing company / branch / department / team **of the same organization**                                                                               |
| `app.prevent_delete_scope_target()`      | Companies, branches, departments and teams referenced by a scoped role assignment cannot be deleted (23503 → API 409)                                                                                  |

Holiday lists are entered by each organization; no statutory or state holiday list is seeded.

## Tables (Phase 04 — employee management)

All tenant-owned with RLS `<table>_tenant_isolation` and composite `(organization_id, employee_id)`
foreign keys to `employees` (CASCADE for profile collections, RESTRICT for documents).

| Table                         | Key columns / constraints                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `employee_settings`           | PK `organization_id`; `number_prefix` (CHECK format), `number_padding` 1–10, `next_number` ≥ 1                                                                                                                                                                                                                                                                                                                                                                                               |
| `employees`                   | `employee_number` UNIQUE per org (CHECK format); `membership_id` UNIQUE (same-tenant trigger, SET NULL on member removal); names; `work_email` citext UNIQUE per org; personal fields (DOB < joining); `date_of_joining`; `probation_status` + dates (CHECK consistency); `notice_period_days` 0–365; `status` + separation fields (CHECK: present exactly when ON_NOTICE/SEPARATED). **No DELETE for `hrm_app`.**                                                                           |
| `employment_records`          | effective-dated placement: `effective_from`, inclusive `effective_to`, `change_type`, `employment_type`, company (composite FK) + optional legal entity, branch, department, team, designation, grade, cost center, manager; **EXCLUDE USING gist** no overlapping periods; partial unique one open record; triggers: same tenant, structure consistency (`app.employment_record_structure_guard`), **append-only history** (`app.employment_record_history_guard`); no DELETE for `hrm_app` |
| `employee_statutory_ids`      | PK `employee_id`; `pan_encrypted`/`pan_last4`, `uan_encrypted`/`uan_last4` (CHECK pairs) — AES-256-GCM                                                                                                                                                                                                                                                                                                                                                                                       |
| `employee_addresses`          | `type` CURRENT/PERMANENT UNIQUE per employee; address CHECKs                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `employee_emergency_contacts` | partial unique one primary per employee                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `employee_family_members`     | relation enum, dependent flag                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `employee_education`          | years 1900–2200, end ≥ start                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `employee_experience`         | end ≥ start                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `employee_certifications`     | expiry ≥ issue                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `employee_skills`             | `name` citext UNIQUE per employee; level enum; years 0–60                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `employee_bank_accounts`      | IFSC CHECK; `account_number_encrypted` + `account_last4`; partial unique one primary                                                                                                                                                                                                                                                                                                                                                                                                         |
| `employee_documents`          | category enum; `content_type` allow-list, size 1 B–10 MB, `sha256` hex, `storage_key` UNIQUE and CHECK-bound to the tenant prefix                                                                                                                                                                                                                                                                                                                                                            |

Extension: `btree_gist` (trusted; created by the migration) for the exclusion constraint.

## Tables (Phase 05 — shifts, attendance and leave)

All tenant-owned with RLS `<table>_tenant_isolation`; employee references are composite
`(organization_id, employee_id)` foreign keys.

| Table                        | Key columns / constraints                                                                                                                                                                                                                                                                                                                                               |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `time_settings`              | PK `organization_id`; leave-year start month 1–12; web/mobile/QR clock-in switches; location requirement; QR rotation 15–300 s                                                                                                                                                                                                                                          |
| `shifts`                     | code (CHECK) UNIQUE per org; local `start_minutes`/`end_minutes` 0–1439 (end ≤ start crosses midnight, start ≠ end); break, grace in/out, full/half-day minutes (half ≤ full), optional overtime threshold, punch window before/after (0–720); partial unique **one default per organization**                                                                          |
| `shift_assignments`          | employee + shift (composite FKs), `effective_from`/`effective_to`; **EXCLUDE USING gist** no overlaps per employee                                                                                                                                                                                                                                                      |
| `roster_entries`             | `UNIQUE(employee_id, date)`; `shift_id` NULL = day off; same-tenant trigger                                                                                                                                                                                                                                                                                             |
| `attendance_punches`         | `punched_at` timestamptz, direction IN/OUT, source WEB/MOBILE/QR/BIOMETRIC_IMPORT/MANUAL, optional `latitude`/`longitude` numeric(9,6) (both or neither), IP, device label, branch (QR); `UNIQUE(employee_id, punched_at, direction)` (idempotent imports); manual punches need a note; **append-only** (trigger + UPDATE/DELETE revoked)                               |
| `attendance_regularizations` | requested in/out (out > in, ≤ 24 h), reason, status PENDING/APPROVED/REJECTED/CANCELLED, decision fields (decided ⇒ timestamp); partial unique **one pending per employee and day**; no DELETE                                                                                                                                                                          |
| `leave_types`                | code UNIQUE per org; paid / tracks balance; accrual NONE/YEARLY/MONTHLY; `annual_quota` numeric(6,2) ≥ 0; prorate; `carry_forward_max`; negative balance; half days; count weekly offs / holidays; min notice 0–365; max consecutive; probation; `employment_types` enum[]                                                                                              |
| `leave_requests`             | type + employee (composite FKs), dates (end ≥ start), sessions FULL/FIRST_HALF/SECOND_HALF, `days` numeric(6,2) in half-day steps (CHECK), routing `approver_employee_id` (same-tenant trigger), status + decision fields; no DELETE                                                                                                                                    |
| `leave_ledger_entries`       | employee, type, leave `year`, entry type OPENING/ACCRUAL/ADJUSTMENT/USAGE/REVERSAL/CARRY_FORWARD/LAPSE, signed `days` numeric(6,2) (sign CHECK per type), accrual `period`, `leave_request_id` (required exactly for usage/reversal); partial unique: one accrual per period, one carry-forward and one lapse per year, one usage/reversal per request; **append-only** |
